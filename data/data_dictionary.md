# Data Dictionary

| Field | Data Type | Description | Example | Notes |
|---|---|---|---|---|
| date | Date | Reporting date | 2026-01-01 | Use yyyy-mm-dd format |
| department | Text | Business function or team | Sales | Replace with anonymized values if needed |
| category | Text | Segment/category/product group | A | Avoid real internal names |
| metric_name | Text | Name of the KPI or metric | Revenue | Define in metric definitions |
| metric_value | Number | Metric value | 1000000 | Mask or scale sensitive values |
| status | Text | Status of process or event | Completed | Example only |

## Notes

- Do not include personally identifiable information.
- Do not include real customer/student/user IDs.
- Do not include internal table names, schema names, workspace IDs, or credentials.
