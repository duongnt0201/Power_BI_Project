# Power BI Files

Place sanitized Power BI files here only if they are safe to publish.

Recommended options:

1. Publish `.pbix` only if it contains sample/synthetic data and no credentials.
2. Publish `.pbit` template only if it does not expose sensitive logic or connections.
3. If unsure, do not publish the Power BI file. Use screenshots and documentation instead.

## Suggested Files

- `dashboard.pbix` - sanitized Power BI file, optional
- `dashboard-template.pbit` - sanitized template, optional
- `dax-measures.md` - DAX measures, sanitized
